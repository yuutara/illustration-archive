桌面版 UI / UX 原型

两套方向使用同一批测试作品（40 件，含多页、GIF、未整理的作品）。可以在两个标签页里分别打开对照。

A · 工作台 整理优先 · 仅作对照

像本地素材管理器：左侧作者 / 标签，中间等高行网格，右侧常驻信息面板。

  • 单击选中、双击或 Enter 看图；Ctrl / Shift 多选后批量设作者和标签
  • 信息面板就地编辑，失焦即保存；看图器共用同一个面板
  • 拖入窗口即导入，进度在底部状态栏
打开原型 A →

B · 画廊 欣赏优先 · 已选定方向

以作品为主的瀑布墙；搜索框同时是作者 / 标签筛选入口。

  • 吸收 A：“选择”或 Ctrl / Shift + 点击多选，底部操作栏批量设作者、标签、删除
  • 吸收 A：方向键移动、空格选择、E 编辑、T 标签等快捷键，按 ? 查看全部
  • 动效与材质实验：左下角“效果”面板逐项开关，Alt + X 一键切换原版 / 新版
  • 新版：纵向按住拖动浏览图库；单图卡片侧向短拉有弹簧牵引；多图作品是循环牌堆，左右拖动换牌
  • 新版材质（效果面板选“液态玻璃”）：图上的编辑、页码、勾选圆点，顶栏搜索、浮层、操作条和看图器统一为玻璃
  • 单击即看图；看图器沉浸，鼠标静止后界面自动隐去
  • 编辑是显式进入的模式，草稿 + 保存 / 取消，切图前提醒未保存
  • 导入在弹层中完成，结束后可给这一批统一设置作者和标签

B 视觉方案 · 暂定 C 暖纸

同一批作品、同一套玻璃控件，两套方案各有浅色和深色。进入后左下角“方案”切换器可随时换（看图器里在顶部），Alt + T 轮换方案、Alt + D 切换浅色 / 深色。

C · 暖纸浅色 · 暂定默认 C · 暖纸深色 · 暂定默认 A · 展厅浅色 A · 展厅深色 B · 微光浅色 B · 微光深色 现版暖纸 · 对照

C · 暖纸（暂定，后续可微调）：羊皮纸为主体，三团极淡的赤陶 / 鼠尾草 / 暖砂环境光，作品平放、颜色不加处理；玻璃只给浮在内容上的控件；唯一强调色是赤陶。
以下仅作对照，不再新增视觉方向。A · 展厅：作品是墙上唯一的颜色；墨色与纸白、衬线标签、近直角画框，唯一的红是一枚朱砂印；浅色看图器是一面亮墙。
B · 微光：全无衬线、圆角卡片、背景淡淡的环境光，靛蓝主色；看图器由作品色调照亮。

原型只在浏览器内存中运行，刷新即恢复测试数据；不连接后端、不读写真实图库。导入可以选择或拖入本机图片做体验，文件不会被复制或上传。
