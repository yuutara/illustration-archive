插画档案 0.6.1 使用说明

插画档案在你自己的电脑上整理插画：导入图片、加作者和标签、搜索浏览。同步 X 点赞和 AI 分析都是可选功能，不配置也能用。
本版只在 Windows 11 x64 上测试过，其他系统未测试。


一、安装

1. 双击文件夹里的安装程序（IllustrationArchive-Setup 开头的 EXE），按向导完成。不需要管理员权限，默认安装到 %LOCALAPPDATA%\Programs\IllustrationArchive。
2. 程序没有数字签名，Windows 可能显示“Windows 已保护你的电脑”。这只说明它不认识这个发布者，并不表示检查出了问题。确认文件来源可信后，点“更多信息”，再点“仍要运行”。
3. 程序自带 Java 运行环境，不需要另外安装 Java。
4. 窗口依赖微软的 WebView2 运行环境，Windows 11 一般已经带有。如果缺少，安装程序会先告诉你，再从微软下载安装，这一步需要联网。

检查文件是否完整：在这个文件夹里打开 PowerShell，运行
    Get-FileHash .\IllustrationArchive-Setup-*.exe -Algorithm SHA256
结果应与 SHA256SUMS.txt 中对应的一行相同（不分大小写）。校验值和安装程序是一起发给你的，所以只能发现文件损坏，不能证明文件没有被人替换。


二、关闭窗口和退出

点窗口的关闭按钮时，应用默认询问你是退出还是留在托盘，可以在“设置 > 关闭窗口时”修改。
留在托盘时应用仍在运行，图标在任务栏右侧，可能收在 ^ 里。右键图标选“退出”才会完全退出。
升级和卸载前必须完全退出，否则安装程序会停下来提示你。


三、数据在哪里

默认在 %LOCALAPPDATA%\IllustrationArchive。以“设置 > 数据”显示的位置为准，那里可以直接打开这个文件夹。

备份：在“设置 > 数据”点“创建备份”，选择保存位置（不能放在数据文件夹里），得到一个 ZIP 文件。期间图库暂停使用，完成后自动恢复。备份包含作品、作者、标签、X 收藏的整理进度和全部原图，不包含 X 登录、API Key 和应用设置；它仍含有你的全部作品，请妥善保管。
恢复：在“设置 > 数据”点“从备份恢复”，选择本应用生成的备份。应用先检查备份并显示内容，确认后用它替换整个图库，备份之后的改动会消失。恢复前的图库原样保留在数据文件夹的 recovery 里，确认不再需要后可以自己删除。图库打不开时，启动失败的窗口里也有“从备份恢复”。
从旧版导入：以前用过服务端版（MySQL）的，在“设置 > 数据”点“从旧版导入”，选择旧版的配置文件 application-local.properties。应用只读其中的数据库地址、用户名、密码和原图文件夹，先复制并核对一份，显示旧版和当前图库各有多少作品，确认后用旧版图库替换整个当前图库，不会合并。旧版的数据库和原图只读不改，密码不会保存。当前图库同样原样保留在 recovery 里。原图缺失或与记录不符时不能导入，会列出有问题的文件；原图存放在 S3 上的旧版不能导入。旧版的 X 登录不会导入，第一次同步时会核对同步进度属于哪个 X 账号。
换电脑恢复后，需要重新连接 X 账号、填写 API Key。以前手动复制的整个文件夹不能用“从备份恢复”打开，仍按原来的方式放回。
config 子文件夹里有你的 X 登录凭据和 API Key，没有加密。手动复制整个数据文件夹给别人之前，请先删除这个子文件夹。


四、升级

直接运行新版本的安装程序覆盖，图库会保留。新版第一次打开时可能需要升级图库，升级之后旧版就打不开了。升级前应用会先自动备份一次，启动画面显示“升级前正在备份图库”，图库越大越久；备份完整写好并核对后才升级。备份放在数据文件夹的 backups 里，文件名以“插画档案备份-升级前”开头，可以在“设置 > 数据”用“从备份恢复”打开；应用不会自动删除它们，确认新版没问题后可以自己删除或移到别处。
自动备份没能完成时（例如磁盘空间不够），图库不会升级，应用会说明原因，让你选择退出或不备份直接打开。
安装程序不允许用低版本覆盖高版本。


五、卸载

在 Windows 的“设置 > 应用”里卸载。卸载只删除程序，不删除图库。不再需要图库时，手动删除数据文件夹；删除后不能恢复。


六、只在本机使用

应用没有账号和登录功能，只监听本机地址。不要用端口转发、反向代理等方式把它暴露到网络上。


七、同步 X 点赞（可选）

- 需要你自己的 X 开发者应用，步骤在“设置 > X 账号”。费用从你的开发者预付额度中扣除，由你自己承担。X 按读取量计费，价格可能调整。建议在开发者控制台设置花费上限，并少量充值。
- 只有点“同步”才会读取，不会在后台自动同步。
- X 的接口不保证和网页上看到的点赞列表完全一致。
- 归档时，帖子的文字会写进作品的备注，可以用搜索找到；这一功能之前归档的作品没有。
- 归档后的作品保存在本机，应用不会再和 X 核对。帖子后来被删除或设为私密，本机的副本也不会变化，请自行遵守 X 的规则。


八、AI 分析（可选）

- 需要你自己的 Gemini API Key，保存在本机 config 子文件夹，没有加密。
- 只有在看图器点“分析这件作品”时，才会把这件作品的静态图片（最多 4 张，最长边缩到 2048 像素）上传到 Google。
- 使用免费额度时，Google 可能用这些内容改进产品，也可能由人工审核，请不要分析隐私或敏感图片。Key 所属项目启用了结算时，按 Google 的价目收费，所以不能保证一定免费。
- Gemini API 只在部分地区提供，中国大陆、香港和澳门不在官方支持列表内。官方条款要求年满 18 岁，并面向专业或商业用途。


九、本版已知限制

- 没有数字签名，也没有自动更新，新版本要手动下载安装。
- 备份每次都是完整的一份，没有定时或增量备份；恢复只能替换整个图库，不能只恢复其中几件作品。
- 从旧版导入只能替换整个图库，不能和当前图库合并。
- AI 分析结果目前不保存，下次要看需要重新分析。
- 桌面版的 Gemini 调用和文字识别还没有用真实 Key 验证过，X 登录过期后的自动续期也没有实际验证过。
- 导入时只检查图片文件头，内容被截断但文件头完好的图片仍可能导入成功。
- 已在全新的 Windows 11 上实测离线安装、打开、升级和卸载重装，不需要另装 Java。缺少 WebView2 时的处理和“Windows 已保护你的电脑”提示没有实测，上面的说明依据的是程序设计和微软的文档。
