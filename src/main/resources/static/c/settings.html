设置

X 账号

X 的接口按量计费，费用记在发起请求的开发者账号上，所以这里连接你自己的 X 开发者应用。只需要设置一次：

  1. 打开 X 开发者控制台，新建一个应用，类型选 Native App。
  2. 回调地址（Callback URL）填：
  3. 建议在控制台设置每月花费上限，再充值少量额度。
  4. 把应用的 Client ID 粘贴到下面。它不是密码，这里也不需要 Client Secret。

授权在你的默认浏览器中进行，应用不会看到你的 X 密码。连接本身不产生费用；只有在“X 收藏”里点同步时才会读取并计费。

AI 分析

获取 API Key

分析时图片会发送给 Google。使用免费额度时，Google 可能用这些内容改进产品，也可能由人工审核，请不要分析隐私或敏感图片。Gemini API 只在部分地区提供，中国大陆、香港和澳门不在官方支持列表内。

网络

连接 X 和 Gemini 时使用。留空时跟随 Windows 代理设置，应用不会更改系统代理。修改后，X 收藏里的图片需要重新打开应用才会走新的代理。

数据

作品、数据库和设置都在这个文件夹里，程序本身不含你的数据。备份：关闭应用后复制整个文件夹。恢复：关闭应用，把备份放回原位。删除程序不会删除图库。config 里有你的 X 登录凭据和 API Key，分享备份前请先删除这个子文件夹。
