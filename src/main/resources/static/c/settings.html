设置

X 账号

可选。本地图库不需要它；只有同步 X 上点赞的作品时才用。

如何创建 X 开发者应用

X 的接口费用记在发起请求的开发者账号上，所以这里连接你自己的应用，只需要设置一次：

  1. 打开 X 开发者控制台，新建一个应用。
  2. 在应用设置里启用 OAuth 2.0，应用类型选 Native App。
  3. 回调地址（Callback URL）填 ，要完全一致，不能写成 localhost。
  4. 建议设置花费上限，再充值少量额度。
  5. 到 Keys and Tokens 复制 Client ID，粘贴到上面。它不是密码，这里也不需要 Client Secret。

已有开发者应用？有 Client ID 不代表能用。Native App 且回调地址已加入才兼容；发过 Client Secret 的 Web App 或 Automated App 不兼容。不确定时新建一个 Native App，不会影响其他程序对旧应用的使用。详见 X 官方说明。

授权在默认浏览器中进行，应用看不到你的 X 密码。授权本身不读取 X 的数据；只有在“X 收藏”点“同步”才会读取，费用从你的开发者预付额度中扣除，不会在后台自动同步。

AI 分析

可选。填写自己的 Gemini API Key 后，看图时可以分析作品、识别日文并翻译。

获取 API Key

上传：只有在看图器点“分析这件作品”时，才会把这件作品的静态图片（最多 4 张，最长边缩到 2048 px）从本机上传到 Google Gemini。费用：Key 所属项目没有启用结算时使用免费额度，用完后会提示稍后再试；启用了结算的项目按 Google 价目计费，所以不能保证一定免费。隐私：使用免费额度时，Google 可能用这些内容改进产品，也可能由人工审核，请不要分析隐私或敏感图片。地区：Gemini API 只在部分地区提供，中国大陆、香港和澳门不在官方支持列表内；官方条款要求年满 18 岁，并面向专业或商业用途。详见 Google 官方说明。

网络

连接 X 和 Gemini 时使用。留空时跟随 Windows 代理设置，应用不会更改系统代理。修改后，X 收藏里的图片需要重新打开应用才会走新的代理。

关闭窗口时

留在托盘时应用继续运行，图标在任务栏右侧，可能收在 ^ 里。点图标回到窗口，右键图标可以退出。

数据

作品、数据库和设置都在这个文件夹里，程序本身不含你的数据，删除程序不会删除图库。config 里有你的 X 登录凭据和 API Key，没有加密；手动复制这个文件夹给别人时请先删除它。

备份与恢复

备份是一个 ZIP 文件，包含作品、作者、标签、X 收藏的整理进度和全部原图；不包含 X 登录、API Key 和应用设置。

正在检查备份…

备份和恢复时图库会暂停使用，由一个小窗口显示进度，完成后自动回到这里。恢复会替换整个图库，恢复前的图库原样保留在数据文件夹的 recovery 里。备份里有你的全部作品，请像保管图库一样保管它。

关于

版本

从备份恢复整个图库？

恢复会用这个备份替换整个图库，备份之后新增或修改的作品、标签和整理进度会从图库中消失。

当前图库会先原样保留在数据文件夹的 recovery 里。X 登录、API Key 和应用设置不变，恢复后不会自动同步或分析。
