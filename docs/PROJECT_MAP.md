# 项目地图

> 给项目主人看的一页，用大白话回答“我们在哪、接下来做什么、什么在等我”。约 60 行，技术细节不放这里。
> 最后更新：2026-11-04。

## 目标

普通用户双击就能用的 Windows 桌面应用：导入和整理插画，同步 X 点赞，用 AI 分析图片。同时是 Java 后端实习的主力项目。

## 路线

代号怎么读：`R3.1` 就是第 3 轮第 1 个工作包。工作包是一块能单独做完、单独验收的事。

| 轮次 | 这一轮解决什么 | 状态 |
| --- | --- | --- |
| 第一轮 能力打通 | 把 X、Gemini、旧库迁移接进桌面版 | 完成 |
| 第二轮 真正的窗口 | 独立窗口、托盘、3 秒启动 | 完成，手感待你验 |
| **第三轮 可交付** | **能发给别人安装使用** | **进行中** |

## 想法池

做到一半想到的事记在这里，不打断当前工作包。到下一个里程碑时一起看。

| 日期 | 想法 | 去向 |
| --- | --- | --- |
| 2026-11-03 | 免充值的 X 点赞来源：官方 API 至少充 5 美元，对多数人是门槛。已有结论：官方数据归档（`like.js`）免费但只有 ID、没有图片地址；抓取类方案违反 X 条款、有封号风险，不做。还要再找有没有更好的替代 | 第四轮第 1 项“官方归档免费导入”的规划时一起调研 |
| 2026-11-03 | 安装后在用户电脑上生成启动加速文件，让用户也有约 3 秒启动（现在约 5–6 秒） | 新工作包候选，要改安装器，需 Codex C 级 |
| 2026-11-03 | 界面改成纯原生 WPF（参考 BiliDesk），图更省内存、滚动更顺、窗口更像原生。初步判断：现在不是 Electron，WebView2 用系统共用的运行时；内存大头是 Java 后端，换 WPF 也还在；要用 C# 重写全部页面和 400 多个 JS 测试，且不加强 Java 后端主线 | 不改方向。先在第四轮“大图库性能”里实测打包版内存与滚动，数据说明 WebView2 是瓶颈时再评估 |
| 2026-11-03 | 换一个比“插画档案”更好的名字，中英文都行，暂无头绪 | 公开发布前决定；改名涉及窗口标题、安装器、快捷方式、数据目录名和说明，数据目录要兼容旧名，宜单独做一个小包 |
